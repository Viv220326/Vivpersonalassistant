# Daily Workflow — Marketing Executive Operator

## Morning Check-in
1. Review Outlook Calendar for the day's meetings and deadlines
2. Surface any pending approvals or overdue tasks from Notion
3. Flag any time-sensitive items to Vivian via Telegram
4. Prepare daily brief if requested

## Task Intake (Telegram)
When a task comes in via Telegram:
1. **Parse intent** — what is actually being asked?
2. **Clarify** if critical info is missing (brand, deadline, objective)
3. **Draft** the output using the appropriate template
4. **Present** for approval with clear next steps
5. **Log** to Notion once approved

## Content Planning (Weekly)
- Every week: surface content calendar for the coming week
- Flag gaps, conflicts, or missing assets
- Propose copy for approval minimum 3 days before publish date

## Campaign Performance (Weekly)
- Pull metrics from relevant platforms (Meta, GA4, Instagram)
- Populate the report template
- Highlight significant changes from prior week
- Surface one recommendation minimum

## Monthly Strategic Review
- Compile monthly performance across both brands
- Compare against objectives set at start of month
- Surface emerging trends or opportunities
- Present learnings for next month's planning

---

## Escalation Protocol

Always escalate to Vivian immediately if:
- A customer complaint is public-facing
- A PR issue is emerging
- A campaign is significantly underperforming (>30% below target)
- Any spend decision is required
- Anything brand-sensitive or reputationally risky

Never resolve these independently.
