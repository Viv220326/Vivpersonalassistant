# Viv Personal Assistant

A curated collection of open-source resources and tools for the Viv personal assistant environment.

## Resources

| Directory | Repository | Description |
|-----------|-----------|-------------|
| `resources/superpowers` | [obra/superpowers](https://github.com/obra/superpowers) | Claude Code extension and plugin system |
| `resources/java-design-patterns` | [iluwatar/java-design-patterns](https://github.com/iluwatar/java-design-patterns) | Java design patterns reference implementations |
| `resources/claude-code` | [anthropics/claude-code](https://github.com/anthropics/claude-code) | Claude Code CLI tool source |
| `resources/everything-claude-code` | [affaan-m/everything-claude-code](https://github.com/affaan-m/everything-claude-code) | Curated collection of Claude Code resources |
| `resources/get-shit-done` | [gsd-build/get-shit-done](https://github.com/gsd-build/get-shit-done) | Productivity tool |
| `resources/awesome-marketing` | [marketingtoolslist/awesome-marketing](https://github.com/marketingtoolslist/awesome-marketing) | Curated list of marketing tools |

## Setup

After cloning this repo, initialize all submodules:

```bash
git submodule update --init --recursive
```

To update all submodules to their latest upstream commits:

```bash
git submodule update --remote
```
